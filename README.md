## Como usar o guia

Se você está chegando agora na unidade Betim, comece pelas seções de horários e mapa. Depois, veja as dicas de estudo, as regras de convivência e as atividades da escola. Quando precisar resolver algo, a seção de contatos explica qual setor procurar em cada situação.

## Como o projeto foi organizado

Cada seção começou como uma issue com uma lista do que precisava entrar no texto. As tarefas ficaram na meta **Entrega 1** e no quadro do projeto. Escrevi cada seção numa branch e liguei o Pull Request à issue com `Closes #número`, para a tarefa fechar quando a seção entrasse na `main`.
